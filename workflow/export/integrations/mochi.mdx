[Mochi](https://mochi.cards) is a modern flashcard app for both spaced repetition and note taking in markdown. 
## Setup
In order to connect Janus to Mochi, you need to share your Mochi API key
- In Mochi, click the username dropdown and then select `Account Settings`
- Scroll down to `API Keys` and then click `Create API Key`.
- Copy your API key to the Janus in the `Settings > Mochi > API Key` ![Mochi Settings](/imgs/mochi-settings.png)
